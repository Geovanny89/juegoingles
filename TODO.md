# HangWord Lab — entregables

- [x] Implementar un juego de ahorcado en React con las 10 palabras técnicas y sus traducciones.
- [x] Mostrar espacios/letras descubiertas, traducción educativa, letras usadas, aciertos, fallos y límite de intentos.
- [x] Crear un muñeco SVG interactivo que reaccione a cada error con una soga progresivamente debilitada y un estado visual final de derrota.
- [x] Hacer más dinámica la figura con sacudidas, balanceo de la soga, destellos de error y animación final.
- [x] Presentar cada reto como una pregunta en inglés con un control para mostrar u ocultar su traducción completa al español.
- [x] Añadir retroalimentación clara de victoria o derrota, revelar la respuesta y permitir iniciar una nueva partida.
- [x] Integrar instrucciones, modo oscuro, diseño moderno y comportamiento responsive para escritorio y móvil.
- [x] Modularizar la arquitectura en componentes, datos y hook de lógica.
- [x] Validar la compilación final, el servidor Vite y el manifiesto de rutas; generar el paquete ZIP para descargar y probar localmente.
